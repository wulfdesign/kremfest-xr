## 🎪 Overview

**KremFest XR** is the dedicated immersive media, 360° cinema, and experimental virtual reality showcase of **KREMFEST**—Seattle’s premier multi-day celebration of forward-thinking electronic music, multimedia art, and nightlife culture at the iconic **Kremwerk / Timbre Room / Cherry** complex.

Described by *The Stranger* as the undisputed monarch of Seattle electronic nightlife and inheriting the mantle of the legendary Decibel Festival, Kremfest brings together international electronic music acts and boundary-pushing visual arts. The **XR Showcase** integrates cutting-edge VR headsets, room-scale installations, and 360° audiovisual journeys directly into the club atmosphere, giving attendees transcendent out-of-body experiences alongside world-class sound.

## 🛠️ Architecture & Dual-Repository Protocol

To preserve total privacy regarding sensitive history, planning notes, and internal operations while publishing a blazing-fast public web presence:

1. **Public Layer (`projects/kremfest-xr`):**
   - Pure, zero-dependency static web application (HTML5, CSS3, modern Vanilla JS).
   - 100% compatible with GitHub Pages hosting (`wulfdesign.github.io/kremfest-xr`).
   - Clean, dark-mode cyberpunk/club aesthetic matching Kremwerk’s visual identity.
2. **Private Sanctuary (`projects/kremfest-xr/private`):**
   - Strictly gitignored from the public repository.
   - Houses an independent local Git repository.
   - Contains confidential collaborator boundaries, raw Google Docs / FilmFreeway submissions, marketing strategy, print brochure generators, QR code tools, and the local Dev Dashboard (`http://localhost:3040`).
